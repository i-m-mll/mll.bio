# Vendored fonts

These font files are vendored so production builds and runtime font loading do
not depend on remote font stylesheets.

- ET Book files were copied from `typeface-et-book@0.0.2`, which packages the
  MIT-licensed ET Book webfonts.
- Inter, Roboto, Roboto Mono, Source Serif 4, Fira Sans, and Iosevka files were
  copied from the matching `@fontsource/*` npm packages. Their license text is
  included in `public/fonts/licenses/`.
